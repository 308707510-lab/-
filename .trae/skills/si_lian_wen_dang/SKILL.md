# 熔炼文档 - 工作思考提炼与总结

## 描述

这是一个用于提炼和总结用户工作思考的技能。当用户输入关键词“熔炼文档”时，智能体将主动回顾和分析用户近期的工作思考记录，提炼核心观点，梳理内容之间的关联，并提供后续延展建议。

## 使用场景

- 用户输入关键词“熔炼文档”
- 用户希望对近期的工作思考进行复盘和总结
- 用户需要从零散的思考中发现模式和关联
- 用户希望获得后续思考和行动的指导建议

## 指令

### 1. 收集思考内容
- 回顾本次会话中用户之前提供的所有工作思考内容
- 如果会话中没有足够的思考记录，主动询问用户提供近期的工作思考
- 记录思考的时间顺序和主题分类

### 2. 提炼核心思考
- 从所有思考内容中提取3-5个核心观点
- 每个核心观点需要有清晰的标题和简要描述
- 识别出最有价值、最具洞察力的思考点

### 3. 梳理内容关联
- 分析各个思考点之间的逻辑关系
- 绘制思考脉络图（用文字描述或列表形式呈现）
- 找出贯穿多个思考的共同主题

### 4. 提供后续延展建议
- 基于当前思考，提出3-5个可以继续深入探索的方向
- 给出具体的行动建议或下一步思考问题
- 推荐相关的学习资源或实践方法

### 5. 输出格式规范
使用以下结构化格式输出思考报告：

```markdown
# 📊 工作思考熔炼报告

## 📌 核心思考摘要
（简要总结整体思考的核心主题和价值）

## 💡 核心思考点
### 思考点1：[标题]
[简要描述]

### 思考点2：[标题]
[简要描述]

...

## 🔗 思考关联图谱
（描述各个思考点之间的关系和脉络）

## 🚀 后续延展建议
### 建议1：[方向]
[具体建议]

### 建议2：[方向]
[具体建议]

...
```

## 示例

### 输入示例
用户之前的思考：
- 今天在做项目规划时，发现需求变更频繁，需要更灵活的应对机制
- 团队沟通效率有待提升，信息传递经常出现偏差
- 最近读了一本关于敏捷开发的书，有一些新的想法想应用到项目中
- 技术债务越来越多，需要制定一个清理计划

### 输出示例
```markdown
# 📊 工作思考熔炼报告

## 📌 核心思考摘要
本次思考围绕项目管理、团队协作、敏捷实践和技术债务四个核心主题展开，体现了对项目质量和团队效率的深度关注。

## 💡 核心思考点
### 思考点1：需求变更管理
项目需求变更频繁，需要建立更灵活的应对机制，确保项目进度不受影响。

### 思考点2：团队沟通优化
团队沟通效率低，信息传递存在偏差，需要改进沟通方式和流程。

### 思考点3：敏捷实践应用
通过阅读敏捷开发相关书籍，希望将敏捷理念引入项目管理中。

### 思考点4：技术债务清理
技术债务积累严重，需要制定系统性的清理计划，避免影响后续开发。

## 🔗 思考关联图谱
这四个思考点紧密相关：需求变更频繁可能导致沟通问题和技术债务增加，而敏捷实践正是解决这些问题的有效方法。敏捷方法中的迭代开发、每日站会等实践可以同时改善需求管理、团队沟通和技术债务问题。

## 🚀 后续延展建议
### 建议1：引入敏捷开发流程
- 下周组织团队进行敏捷开发培训
- 尝试2周一个迭代的开发模式
- 建立每日站会制度

### 建议2：建立需求变更管理流程
- 制定需求变更评估标准
- 建立变更影响分析机制
- 与客户建立更频繁的反馈循环

### 建议3：技术债务清理计划
- 本周五前完成技术债务盘点
- 每个迭代预留20%时间用于清理技术债务
- 建立代码审查机制防止新的技术债务产生

### 建议4：团队沟通工具优化
- 调研并引入团队协作工具
- 建立文档共享和版本管理机制
- 定期组织团队沟通复盘会议
```
