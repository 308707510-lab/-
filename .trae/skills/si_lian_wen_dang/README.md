
# 熔炼文档 Skill

## 简介

"熔炼文档"是一个用于提炼和总结工作思考的Skill。当你输入关键词"熔炼文档"时，AI会自动回顾和分析你近期的工作思考，提炼核心观点，梳理内容之间的关联，并提供后续延展建议。

## 功能特性

- 📊 **核心思考提炼**：从零散的思考中提取最有价值的核心观点
- 🔗 **内容关联分析**：梳理思考点之间的逻辑关系，发现隐藏的模式
- 🚀 **后续延展建议**：基于当前思考，提供具体的行动方向和探索建议
- 📝 **结构化输出**：生成清晰、易读的思考报告

## 安装方式

### 方式一：在项目中使用（推荐）

1. 将 `si_lian_wen_dang` 文件夹复制到项目的 `.trae/skills/` 目录下
2. 重新启动 TRAE IDE
3. Skill 会自动加载

### 方式二：全局使用

1. 将 `si_lian_wen_dang` 文件夹复制到全局Skill目录：
   - macOS/Linux: `~/.trae/skills/`
   - Windows: `%userprofile%/.trae/skills/`
2. 重新启动 TRAE IDE
3. Skill 会在所有项目中生效

## 使用方法

### 基本使用流程

1. **准备文件**：将你的工作思考记录保存为Markdown（.md）或纯文本（.txt）文件
2. **触发熔炼**：当你想要总结时，输入关键词"熔炼文档"并提供文件路径
3. **获得报告**：AI会读取文件内容并自动生成结构化的思考报告

### 使用示例

#### 示例1：提供文件路径

```
你：熔炼文档 /path/to/your/work-summary.md
```

或者更自然的方式：

```
你：熔炼文档，请读取我的工作总结文件：工作记录.md
```

#### 示例2：完整使用流程

1. 首先准备一个 `工作记录.md 文件，内容如下：
```markdown
# 工作思考记录

## 5月20日
今天在做项目规划时，发现需求变更频繁，需要更灵活的应对机制

## 5月21日
团队沟通效率有待提升，信息传递经常出现偏差

## 5月22日
最近读了一本关于敏捷开发的书，有一些新的想法
```

2. 然后输入：
```
你：熔炼文档 工作记录.md
```

3. AI会读取文件并生成思考报告

## 输出结构

生成的思考报告包含以下部分：

1. **核心思考摘要**：简要总结整体思考的核心主题和价值
2. **核心思考点**：列出3-5个最有价值的思考观点
3. **思考关联图谱**：描述各个思考点之间的关系和脉络
4. **后续延展建议**：提供3-5个可以继续深入探索的方向和具体建议

## 最佳实践

1. **定期记录**：养成随时记录思考的习惯，不要等到最后才整理
2. **详细描述**：记录思考时尽量详细，包含背景、想法和疑问
3. **定期熔炼**：建议每周或每个项目阶段进行一次"熔炼文档"
4. **迭代优化**：根据AI的建议，持续迭代和完善你的思考

## 自定义配置

你可以根据自己的需求修改 `SKILL.md` 文件中的内容：

- 调整核心思考点的数量
- 修改输出格式
- 添加或删除分析维度
- 自定义建议方向

## 常见问题

### Q: 支持哪些文件格式？

A: 目前支持Markdown（.md）和纯文本（.txt）格式。

### Q: 如果没有提供文件，直接输入"熔炼文档"会怎样？

A: AI会主动询问你提供工作总结文件的路径。

### Q: 文件需要什么格式？

A: 文件格式没有严格要求，只要包含你的工作思考内容即可。可以按日期、主题或其他方式组织内容。

### Q: 可以跨会话使用吗？

A: Skill会在当前会话中读取你提供的文件。建议将思考记录保存到文件中，随时可以进行熔炼。

### Q: 文件应该放在哪里？

A: 文件可以放在项目目录中的任何位置，只要提供正确的路径即可。
