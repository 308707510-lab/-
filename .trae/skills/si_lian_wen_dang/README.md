
# 熔炼文档 Skill

## 简介

"熔炼文档"是一个用于提炼和总结工作思考的Skill。当你输入关键词"熔炼文档"时，AI会自动回顾和分析你近期的工作思考，提炼核心观点，梳理内容之间的关联，并提供后续延展建议。

## 功能特性

- 📊 **核心思考提炼**：从零散的思考中提取最有价值的核心观点
- 🔗 **内容关联分析**：梳理思考点之间的逻辑关系，发现隐藏的模式
- 🚀 **后续延展建议**：基于当前思考，提供具体的行动方向和探索建议
- 📝 **结构化输出**：生成清晰、易读的思考报告

## 安装方式

### 方式一：在项目中使用（推荐）

1. 将 `si_lian_wen_dang` 文件夹复制到项目的 `.trae/skills/` 目录下
2. 重新启动 TRAE IDE
3. Skill 会自动加载

### 方式二：全局使用

1. 将 `si_lian_wen_dang` 文件夹复制到全局Skill目录：
   - macOS/Linux: `~/.trae/skills/`
   - Windows: `%userprofile%/.trae/skills/`
2. 重新启动 TRAE IDE
3. Skill 会在所有项目中生效

## 使用方法

### 基本使用流程

1. **记录思考**：在日常工作中，随时向AI分享你的工作思考和想法
2. **触发熔炼**：当你想要总结时，输入关键词"熔炼文档"
3. **获得报告**：AI会自动生成结构化的思考报告

### 使用示例

#### 示例1：日常思考记录

```
你：今天在做项目规划时，发现需求变更频繁，需要更灵活的应对机制
你：团队沟通效率有待提升，信息传递经常出现偏差
你：最近读了一本关于敏捷开发的书，有一些新的想法想应用到项目中
你：技术债务越来越多，需要制定一个清理计划
你：熔炼文档
```

AI会自动生成思考报告。

#### 示例2：单次深度思考

```
你：我一直在思考如何提高代码质量，有几个想法：
     1. 建立更严格的代码审查机制
     2. 引入自动化测试工具
     3. 制定代码规范文档
     4. 组织技术分享会
你：熔炼文档
```

## 输出结构

生成的思考报告包含以下部分：

1. **核心思考摘要**：简要总结整体思考的核心主题和价值
2. **核心思考点**：列出3-5个最有价值的思考观点
3. **思考关联图谱**：描述各个思考点之间的关系和脉络
4. **后续延展建议**：提供3-5个可以继续深入探索的方向和具体建议

## 最佳实践

1. **定期记录**：养成随时记录思考的习惯，不要等到最后才整理
2. **详细描述**：记录思考时尽量详细，包含背景、想法和疑问
3. **定期熔炼**：建议每周或每个项目阶段进行一次"熔炼文档"
4. **迭代优化**：根据AI的建议，持续迭代和完善你的思考

## 自定义配置

你可以根据自己的需求修改 `SKILL.md` 文件中的内容：

- 调整核心思考点的数量
- 修改输出格式
- 添加或删除分析维度
- 自定义建议方向

## 常见问题

### Q: 如果没有记录思考，直接输入"熔炼文档"会怎样？

A: AI会主动询问你提供近期的工作思考内容。

### Q: 可以跨会话使用吗？

A: 目前Skill主要在单次会话中生效。建议在同一个会话中记录思考并触发熔炼。

### Q: 可以保存思考记录吗？

A: 建议你在记录思考时，同时将重要内容保存到本地文件或笔记软件中。
